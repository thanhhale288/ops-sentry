# SOP-ACCESS — Physical access control

Access control systems (ACS-*) enforce two-person entry to server rooms and dual-factor at docks after 22:00.

Forbidden remote actions: unlock all doors, disable door alarms, badge-clone, hold-open longer than 30 seconds without a named visitor ticket.

A failed ACS-02 dock reader is P1. Create a work order for on-site security and keep the dock closed until a human verifies identity.

Server room ACS-11 requires CCTV recording of every badge event. If recording is down, deny entry even if the badge is valid.
