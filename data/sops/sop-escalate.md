# SOP-ESCALATE — On-call matrix

P1: page the site supervisor and the domain owner (security / BMS / DPO) within the device SLA.
P2: work order to the day technician; Slack the channel #helio-ops.
P3: backlog, no page.

This agent may create work orders. It may not page executives, post to public channels, or send resident SMS.

If SLA minutes are 15 or below, the priority label is P1. If 120 or below, P2. Otherwise P3.
